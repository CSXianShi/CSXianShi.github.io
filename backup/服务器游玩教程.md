## 一、准备 PCL 启动器

### 1. 下载 PCL

从这里下载 PCL 启动器：

[PCL 启动器下载](https://ltcat.lanzouv.com/b0aj6gsid)

提取码：`pcl2`

下载后解压到一个单独的文件夹，运行其中的 `PCL.exe`。不要直接在压缩包里启动，也不要把启动器放在桌面后随意移动游戏文件夹。

### 2. 创建游戏账号

打开 PCL 后，点击左侧的账号区域，选择“添加正版”或“添加离线账号”。

本服务器使用离线登录模式，第一次进服需要在服务器内注册密码；PCL 里的离线账号名称就是你在服务器里的玩家名。建议使用稳定、容易辨认的英文或数字名称，不要频繁更换。

## 二、安装 Minecraft

1. 在 PCL 左侧打开“下载”。
2. 选择 Minecraft Java 版 `1.21.11`，安装纯净版本。
3. 如果 PCL 提示 Java 不存在，允许它安装或选择 **Java 21**。Minecraft 1.21.11 不要使用过旧的 Java 8。
4. 第一次启动建议给游戏分配 2GB 以上内存；电脑内存充足时可分配 4GB。
5. 等待下载完成后，从 PCL 启动游戏一次，确认能进入主菜单，再连接服务器。

## 三、加入服务器

1. 在 Minecraft 主菜单点击“多人游戏”。
2. 点击“添加服务器”。
3. 服务器名称可以随意填写，例如：`生存服`。
4. 服务器地址填写：

   `play.ultra-x.top`

   这个域名会自动解析到当前游戏端口 `ragame.top:23068`。如果你的客户端无法识别 SRV 记录，再使用备用地址：

   `ragame.top:23068`

5. 点击“完成”，双击服务器列表中的服务器即可进入。

服务器版本为 Purpur `1.21.11`，是纯净生存服，支持 Java 版和基岩版互通。服务器会自动下发音乐资源包；首次进入或资源包更新时请等待下载完成。

## 四、第一次进入：注册和登录

服务器使用 AuthMe 保护玩家账号。

第一次进入服务器时，游戏会自动打开一个独立的注册窗口。按照窗口提示设置密码并再次确认，然后提交即可进入游戏，不需要在聊天栏输入注册指令。

以后再次进入服务器时，会自动打开登录窗口。输入之前设置的密码并提交即可。

如果登录窗口没有正常出现，可以按 `T` 打开聊天栏，使用备用指令：

```text
/register 自定义密码 自定义密码
/login 你的密码
```

不要把自己的密码发到公屏，也不要使用与其他网站相同的密码。

## 五、常用指令

```text
/sethome       设置家
/home          返回家
/tpa 玩家名    请求传送到其他玩家
/tpaccept      接受传送请求
/spawn         返回出生点
/music list    查看音乐歌单
/music play 1  播放或排队播放第 1 首歌
/music now     查看当前播放
/music queue   查看播放队列
```

普通玩家可以使用点歌、队列和传送功能。管理员切歌和停止播放使用 `/music skip`、`/music stop`。

## 六、常见问题

### PCL 打不开或游戏闪退

确认 PCL 已解压，Java 版本为 21，并把游戏内存调到至少 2GB。不要同时启动多个 Minecraft 实例。

### 找不到服务器

先确认地址没有多余空格，优先使用 `play.ultra-x.top`；仍然无法连接时使用 `ragame.top:23068`。服务器维护或重启期间请稍后再试。

### 进服后没有音乐

等待资源包下载完成后重新进入服务器。在“选项 → 资源包”中确认服务器资源包已启用；如果仍无声音，检查游戏主音量和“音乐”音量，并重新连接一次服务器。

### 提示账号未登录

正常情况下进服后会自动出现登录窗口。窗口未出现时，按 `T` 打开聊天栏，输入 `/login 你的密码`；首次进入则使用 `/register 密码 密码`。
